HOW TO GENERATE / SYNC JPGs DIRECTLY
==================================================
Simply double-click `sync_assets.bat` inside the `TerraPulse_UI_Assets` folder.
This will copy all source captures and automatically encode them as high-quality (95% quality) JPGs directly into:
- `01_Website_Screenshots/*.jpg`
- `02_Selected_Screenshots/Search.jpg`
- `02_Selected_Screenshots/Change.jpg`
- `02_Selected_Screenshots/Review.jpg`
- `03_Final_PPT_Visual/TerraPulse_Sample_UI.jpg`
